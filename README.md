# ЛР2: распознавание рукописных китайских иероглифов

Программа распознает 10 классов иероглифов с помощью многослойного перцептрона на NumPy. Интерфейс написан на Tkinter. В проект включены датасет 32x32 BMP и проверенные веса модели.

## Запуск в PyCharm

1. Откройте папку `LR2_Chinese_MLP` как проект.
2. Выберите интерпретатор Python 3.10 или новее и установите зависимости: `python -m pip install -r requirements.txt`.
3. Запустите `src/gui_app.py`.

Сохраненные веса загружаются при запуске. Для нового обучения задайте параметры и нажмите «Обучить с нуля». Графики текущего обучения открываются кнопкой «Графики».

## Воспроизводимый запуск

Из корня проекта:

```powershell
python src/run_experiment.py
```

Результаты сохраняются в `src/output`. По умолчанию используются два скрытых слоя (96 и 48 нейронов), ReLU, 50 эпох, learning rate 0.05, batch size 32 и seed 34. Разбиение выполняется программно: по 80 изображений каждого класса для обучения и по 20 для проверки.

Для повторения сравнений из отчета:

```powershell
python src/compare_hyperparameters.py
```

## Состав

- `src/lab2_core.py` — подготовка данных, MLP, обучение, метрики и сохранение весов.
- `src/gui_app.py` — интерфейс, холст, распознавание и интерактивные графики.
- `src/run_experiment.py` — обучение без интерфейса и сохранение результатов.
- `src/compare_hyperparameters.py` — сравнение настроек модели.
- `data/Chinese_Dataset` — 1000 BMP-изображений и `annotations.csv`.
- `src/output/model_mlp.npz` — проверенные веса для запуска без обучения.

Методички и отчет в проект не включены: они не нужны для работы программы.
